\section*{Status and Erratum (v1.0.1)}
Version 1.0.0 reported a per-step relaxation latency of 144.7\,ms, a Quantum ESPRESSO results table for five generated candidates (including BaBiTe), and a DiffCSP-SC loss table. On re-audit, none of these figures is backed by measurement outputs in this repository; they are \textbf{withdrawn}. This version describes the architecture and the components verifiable from the published code. See \texttt{paper/SuperCon\_Zero\_Copy\_Discovery.md} for the full text.

\section*{Abstract}
We describe a closed-loop pipeline for superconductor candidate screening on a unified-memory workstation (AMD Ryzen AI Max+ 395 / Strix Halo, ROCm): Magpie-style compositional screening, a DiffCSP-style structure generator, a C++/HIP relaxation layer using \texttt{hipHostMallocMapped} buffers wrapped by \texttt{torch::from\_blob} (no explicit host--device copies), and a hand-off to Quantum ESPRESSO. On Strix Halo there is no PCIe link between CPU and iGPU; any benefit of the zero-copy design stems from avoided copy and dispatch overhead and must be established by a same-GPU mapped-vs-copied benchmark, which is pending. Quantitative performance and DFT results will be published only together with raw outputs.
